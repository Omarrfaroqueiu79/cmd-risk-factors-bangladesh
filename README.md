# Prevalence and Risk Factors of Common Mental Disorders (CMD) Among University Students in Bangladesh: A Cross-Sectional Study

This repository contains the dataset and complete statistical and machine learning analysis pipelines for evaluating Common Mental Disorders (CMD) and associated digital behavioral, physical, and psychosocial risk factors among university students.

## Contents
- `CMD_Pipeline_BMC_Final.py`: Full machine learning and statistical pipeline configured for BMC Public Health formatting and high-resolution figure generation.
- `CMD_Pipeline_PLOSONE_Final.py`: Full pipeline configured for PLOS ONE formatting.
- `CMD_Final_Pipeline_singlecell.ipynb`: Interactive Jupyter Notebook containing the full pipeline executable cell-by-cell.
- `CMD_Pipeline_PLOSONE.ipynb`: Jupyter Notebook configured for PLOS ONE workflow.
- `Data_Final.sav`: Complete study SPSS dataset.
- `SPSS/`: Contains SPSS syntax routines (`.sps`), study data files (`.sav`), and analysis output files (`.spv`) for bivariate and multivariable analyses.
